# Self-evaluation
The project and report was carried out on my own. The overall result of the project is satisfying, though it could have very well be completed in much less time. The most difficult part has been the application backend developmnet, as I had decided to not use any help from AI to produce the code. The use of Flask was not quickly intuitive and I had to face some issues, in particular dealing with the saving and siaplying the plots once generated. Once again, the application is fully functional, even though its logics are fairly simple, which I consider a success, as it is the first time I carry out a project fo this kind. 
The HTML and CSS sections, where intially done without any help from AI, but the graphical aspect was not satisfactoy, therefore I have opted to generate code using ChatGPT, giving very simple prompts (such as "make it look better"), submitting the code I had produced. Overall, the pages generated by ChatGPT were better looking than the ones I was able to produce myself, so I decided to stick with those. 
For what concerns the production of this report, the work was prett straight forward, once I understood its logic and structure.
