# User Guide
This section explains gow to use the Helpinvest web application from the user's perspective, assuming that it has been correctly deployed nad is accessibale throug a web browser.
## Accessing the Application
Onceh the appliocation is running, the user can access Helpinvest by opening th eprovided URL in a web browser. The homepage presents a form that allows the user to configure a savings and investment scenario. In addition, in the homepage it is possible to find a link to an informative page on the concept of compound interest, and the information on how the different rates (based on different levels of risk averision) weere considered. 
## Entering investing parameters
On the homepage, the user is required to provide the following information:

- **Invesment duration (years):** the number of years for which the user plans to invest. Longer time horizons better highluight the effects of compound interest.
- **Initial capital:** the starting amount invested at the beginning of the savings plan.
- **Monthly deposit:** the fixed amount contributed every month throughout the investment period
- **Risk profile:** the level of investment risk selected by the user. Available options are low, medium and high, each corresponding to different expected return rates.

Each input field is accompanied by a briefe description of what it should contain, in order to help the user understand its purpose.

## Submitting the form 
Once the required information is entered, the user can generate the plots by clicking the **"GO!"** button. The application processes the data and calculates the pojected evloution of the savings plan over time. If any of the required fields are not filled, the application will notfiy the user with the required information that is needed to proceed. 

## Viewing the results **

Once the computation is complete, the user is redirected to a results page displaying a graphical representation of the portfolio value over the selected time horizon. 
The graph shows:
- A **high return scenario**
- An **average return scenario**
- A **low return scenario**
- A **no-return scenario adjusted for inflation**

The visual comparison should help the user understand the impact of different risk levels and compound interest over time. 

## Modifying inputs
Once in the results page, the user can return to the homepage by clicking the "**Go back**" button. This allows the user to modify the input parameters and generate a new simulation.
