# Helpinvest

HelpInvest is a small web application built with Flask that simulates how an investment portfolio can grow over time. The user enters a starting capital amount, monthly deposits, an investment duration, and a risk profile. Based on these inputs, the application estimates how the portfolio value evolves using compound growth and different return rates.

The backend performs the financial calculations and generates a graph that compares several scenarios, including low, average, and high returns, as well as a scenario adjusted for inflation. This graph is then displayed on the results page of the website.

The project combines Python for the application logic, Flask for the web framework, and HTML and CSS for the user interface. Matplotlib and NumPy are used to handle numerical calculations and to create the portfolio growth visualization.

This project is intended for educational purposes and demonstrates how financial simulations, data visualization, and web development can be integrated into a single application.
